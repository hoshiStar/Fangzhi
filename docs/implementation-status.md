## 仍需后续处理

1. 索引加载仍是整份读进内存（主进程 + 每个 worker 各一份），索引到几百 MB 时需要改成按需 mmap 或分片读取；构建侧的分批落盘已经解决，加载侧还没。
2. 小程序真实 AppID、真机渲染和发布验收。
3. PDF Range、损坏文件、OCR 字错率等更大规模的专项自动化测试。
4. 识别模型首次使用需联网从 ModelScope 下载（约 100 MB），当前只有失败日志提示，没有内置下载进度。
5. 查询未做真正的分词：连写能命中的前提是书名在查询里连续出现；`嘉慶贛州府誌`（错字或字序不同）仍只会落到「近似」一档。
